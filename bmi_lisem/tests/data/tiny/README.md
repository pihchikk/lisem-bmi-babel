# Tiny synthetic catchment (CI test data)

A 10×10 synthetic OpenLISEM catchment used to exercise the BMI in CI without a
real dataset.

## What is committed

- `make_tiny.py` — generator that writes the PCRaster `.map` inputs (needs
  `pcraster`).
- `tiny.run` — runfile **template** (relative paths).
- `rain.txt` — a short rainfall table.

The `.map` binaries are **not committed** — they are generated by `make_tiny.py`
(the `.gitignore` in this folder excludes `*.map`). The test fixture
(`bmi_lisem/tests/_runfile.py`) uses `tiny.run` only when `ldd.map` exists, so
without generation the data-dependent tests skip.

## Generate locally

```bash
pip install pcraster
python bmi_lisem/tests/data/tiny/make_tiny.py
LISEM_TEST_RUNFILE="$(pwd)/bmi_lisem/tests/data/tiny/tiny.run" pytest -q bmi_lisem/tests
```

## Honest status

This is a **scaffold**. The exact set of mandatory maps and the runfile key
names are specific to the vendored OpenLISEM build and have **not** been
validated end-to-end in this environment (no engine/pcraster available at
authoring time). Before the data-dependent tests can be relied on:

1. Run `make_tiny.py` and `initialize("tiny.run")` against the built engine.
2. For every "missing map" / "unknown key" error, add the map to `make_tiny.py`
   (with a physically sensible uniform value) and/or fix the key in `tiny.run`,
   cross-checking `openlisem_bmi/model/lisRunfile.cpp`.
3. Once `initialize()` + a full event run succeed, commit the finalized
   `make_tiny.py` / `tiny.run`.

Until then CI's `test.yml` proves the native build + Cython binding via the
no-data smoke tests; the physics/metadata tests skip.
